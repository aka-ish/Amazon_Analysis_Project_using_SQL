## 📌 Project Overview
This project is a **pure SQL-based analysis** of an Amazon-like e-commerce database.  
It focuses on extracting **business insights** related to **sales, customers, inventory, payments, and logistics** using **MySQL**.

The goal is to demonstrate **real-world SQL analytics**, not just query writing.

---

## 🧱 Dataset
The analysis is performed on **9 relational tables**, including:
- customers
- orders
- order_items
- products
- categories
- inventory
- payments
- shipping
- sellers

---

## 🔍 Key Business Questions Solved
- Top revenue-generating products
- Month-over-Month revenue growth
- Customer Lifetime Value (CLTV) & ranking
- Least-selling categories by state
- Low-stock inventory risk
- Payment success vs failure rate
- Orders with multiple payment attempts
- Return rate by product category
- Average delivery time by state

---

## 🛠️ Tech Stack

## ⚡ Highlights
- Used **window functions** (`DENSE_RANK`, `ROW_NUMBER`, `LAG`)
- Optimized slow queries using **indexes**
- Fixed schema issues (`TEXT → VARCHAR`, proper DATE types)
- Applied **real business logic** (completed orders, realized revenue)
- Debugged real performance issues using `EXPLAIN`
